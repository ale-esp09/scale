# Scale

App personale per trovare scala e interno inquadrando una busta.

**Questo archivio contiene solo il programma, nessun dato.** I nomi vengono caricati sul telefono e restano solo lì (memoria del browser). La lettura del testo avviene sul telefono con [Tesseract.js](https://github.com/naptha/tesseract.js) (licenza Apache 2.0, file in `vendor/`). La pagina non può inviare dati ad altri siti (vedi la Content-Security-Policy in `index.html`).
